# Still · Energy at your pace

14 个 390 × 844 高保真、非交互英文手机界面。根据提供的作业整理文本制作；未获得原始课程手册，不能核验整理文本之外的要求。SVG 为可导入 Figma 的矢量素材，不是原生 .fig 文件。预览 PDF 由本地绘图工具生成，不是 Figma 导出文件，不能代替课程要求的最后导出步骤。

## 在 Figma 完成最终交付

1. 新建 Design 文件，建一个页面 `Still — Final prototype`。
2. 将 `screens` 文件夹中的 14 个 SVG 拖入画布；只导入 SVG，不要导入 preview PNG。
3. 每个界面创建一个 390 × 844 Frame（选中导入的界面，使用 Frame selection，并检查尺寸）。以文件序号命名 Frame，确保所有界面内容在对应 Frame 内。
4. 按顺序排列：01 Today；02 Log activity；03 Activity saved；04 Symptoms；05 Symptoms saved；06 History；07 Comparison；08 Adjust plan；09 Scale down；10 Plan updated；11 Energy limit；12 Limit saved；13 Defer；14 Stop。
5. 若想按流程查看，可将 13、14 放在 08 旁边；10 是三种计划调整后的汇总状态，最后一次调整为缩减晚餐。
6. 使用 Figma 的 Export frames to PDF 功能，导出全部界面。不要建立交互连线，作业要求非交互原型。
7. 打开导出的 PDF，检查 14 个界面均存在、文字可读、没有裁切、遮挡或空白页，再上传 Canvas。课程截止以课程平台和教师最新说明为准。

建议安装 DejaVu Sans，以保持字体与预览一致。SVG 导入后字体和图层可编辑情况取决于 Figma 的导入行为；如文字被转换为轮廓，它仍然是矢量，但须重新创建文字图层才能改写。

## 需求覆盖

| 要求 | 界面证据 |
|---|---|
| UR1 已用、剩余、额度 | 01、03、12；35/60 → 45/60 → 45/50 |
| UR2 活动与身体／认知／情绪消耗 | 02；点数和首页明确一致，03 保存反馈 |
| UR3 快速症状记录 | 04；三项有文字定义，备注可选，05 保存反馈 |
| UR4 延迟 24–72 小时症状 | 06、07；5 Oct 活动与 7 Oct 症状同屏，措辞不宣称因果 |
| UR5 缩减、推迟、停止 | 08、09、13、14 操作，10 汇总结果与撤销 |
| UR6 暂定额度与逐渐调整 | 11 近期记录、暂定估计帮助、增减控件；12 更新结果 |

DC1–DC5：没有打卡、徽章、活动奖励、最佳表现或增长目标；不责备休息；主按钮高 54，选项至少高 48；深色背景和文字标签避免仅靠颜色；不诊断、不推荐增加活动、不声称点数具有医学准确性。

## 已完成的静态启发式检查

- 一致性：所有界面使用相同点数、卡片、按钮和语言。
- 可用性：保存按钮在底部，核心表单一屏完成，症状三项直接选择。
- 反馈和结束：活动、症状、额度均有独立保存结果和 Done。
- 防错：区分“计划估计”与“已经消耗”，调整计划不会改变已用点数。
- 撤销：保存结果提供 Undo；计划结果撤销最后一次更改。
- 用户掌控：每个修改界面提供取消／保留选择。
- 减少记忆：调整额度时展示近期数据，延迟关系比较同屏呈现。
- 检查发现并修正：首页长标题超出画布，改为 Space for today；删除界面中的实现说明，改为用户可理解的额度说明。

这些是设计审查，不是实际用户测试、临床验证或交互功能测试。静态控件不会真的保存数据。
