# 你的 SVG 修改版 · Pace

依据上传的 1.svg（六个手机界面）重新整理。原文件将所有文字转成轮廓，无法直接改写，因此重建了文字、卡片和控件，保留原来的六项核心页面结构和个人精力单位体系；未直接修改在线 Figma 文件。

## 下载与导入

1. 下载 Revised_Figma_Import.zip 并解压。
2. 在原 Figma 文件新建 Page：Revised。保留原版作为备份。
3. 将 screens 中的 14 个 SVG 一起拖入画布。每个 SVG 的外部尺寸为 440 × 956。
4. 每个导入对象分别 Frame selection，检查 Frame 尺寸和内容完整性，命名与文件序号一致。
5. 最终 Frame 按顺序从左到右排列，再用 File → Export frames to PDF。不要用一个巨大的总览 Frame 代替各手机 Frame。
6. 本目录 PDF 是本地预览，并非 Figma 导出的最终作业文件。检查 Figma 最终 PDF 有 14 页，内容无裁切。

字体为 DejaVu Sans。SVG 文字使用 text 元素，而不是路径轮廓；具体导入后的图层结构和可编辑性须在 Figma 中确认。SVG 无 Auto Layout、组件关系及真实交互功能。本作业要求非交互原型。

## 修改理由与静态评估

- 统一暖白背景、深绿文字与按钮，去除照片背景和抢注意力的色块；所有状态都有文字标签。
- 活动录入去除输入前没有信息价值的柱状图，三个大号数值控件直接记录消耗；备注不强制。
- 症状选项带明确文字含义；没有责备、奖励、打卡或增加活动的目标。
- 计划选项明确标注动作，不用不清楚的红色 X 代替停止。
- 不提供诊断、医学阈值或恢复建议；预算是个人可修改的估计。
- 核心操作按钮、选项和增减控件至少 46 设计单位高（导入后按 440 宽缩放）。
- 保存有结束状态、Done 和 Undo；计划估计与已记录消耗分开说明。
- 已检查横向文字边界和数据合计，并人工查看界面总览；这不等同于真实用户测试或交互测试。

已知限制：没有单独展示记录删除／编辑的结果或超额度首页，未将静态控件实现为功能。提交要求按用户提供的整理文本核对，未收到原始课程手册。
