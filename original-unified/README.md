# 原稿基础上的统一风格修改版

这版保留原六页功能与主要内容顺序：Home、History、Adjust budget、Log activity、Plan、Activities。修改了原有组件风格和局部排版，没有采用之前重做版的 Pace/Still 模板，没有增加新品牌或替换六页结构。

## 本版统一的规则

- 页面底色 #EEE9E5；卡片 #FAF7F3；内层区域 #E5DFDC / #E9E3E0。
- 主文字 #302C32；主操作与选中状态 #655366，白色文字；边线 #BEB2BA。
- 保留原橙色精力圆；三个消耗柱分别使用低饱和灰紫、灰蓝、灰褐，并保留类型文字和数值。
- 保留原衬线字形；新文字使用 Times New Roman / Liberation Serif。原导出时已转为轮廓的文字只修改颜色与位置，未强行换成另一套字体。
- 核心操作按钮高48，首页两个记录入口高56；按钮圆角8，卡片圆角12。紧凑列表入口使用36高的次按钮。
- 各页主内容左右留白以24为基准；新增按钮成对或成组三列排列，不再另塞一个不同风格的按钮。

## 删除及改动

Home：移除照片背景、右侧无标签工具栏、语音条及不清楚的时间尺。保留顶部活动列表、橙色圆、已用额度和底部历史／预算入口。Log activity 和 Log symptoms 在原记录区成对排列；底部改为日期与两个同样式次按钮。

History：保留两天记录、今日状态、四个症状选项和保存入口。卡片底色与其他页统一，Severe 用同款主色选中；单位、日期和24–72小时关系说明更清楚。

Adjust budget：保留原弹窗及滑尺。统一标题栏、底色、选中滑块、Save/Cancel；清除重叠的80%文字，展示近期记录及暂定额度帮助。

Log activity：保留原名字输入、三类消耗、柱图及数值控件。列中心统一对齐，三组增减控件各112宽、44高，实际示例4+1+0=5；移除背景和语音栏，保存/取消与其他页同款。

Plan：保留列表与勾选方式，删除重复占位行，只保留5项明确活动。选中Chat with friends时，在原列表下方展示当前18分钟/6units、缩短为9分钟/3units及明天4Oct的示例选项。Stop、Shorten、Defer使用相同尺寸、颜色和间距。

Activities：保留展开式列表和原柱图，修正12+2+4=18；柱图颜色降饱和，单位一致；Edit/Delete使用同款主次按钮，记录入口使用主按钮。

## 文件与 Figma 导入

- Unified_Original_Layout.svg：1400×2004的六屏总画布。
- screens：六个独立440×956的SVG，推荐导入这些文件。
- After.png：修改后总览。
- Before_After.png：原稿与本版对照。
- Unified_Original_Preview.pdf：六页本地预览；最终提交仍需从Figma导出PDF。

新建Figma Page，拖入screens里的六个SVG。逐个Frame selection，检查尺寸440×956，按01至06从左到右摆放。使用File → Export frames to PDF。保留原文件作为备份。

SVG不会保留原Figma的Auto Layout、组件或交互；修改过的文字为text元素，未修改的轮廓文字仍是路径。请安装Times New Roman或Liberation Serif，并检查Figma导入后字体是否替换。
